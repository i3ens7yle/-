# โปรแกรมลงเวลาพนักงาน อาม่า แคมป์ (ทำงานบนคอมในร้าน)

โปรแกรม Windows ไฟล์เดียว: เปิดบนคอมเครื่องแม่ → พนักงานต่อ Wi-Fi ร้านแล้วสแกน QR ลงเวลาด้วยมือถือตัวเอง
ไม่ต้องใช้อีเมล/Google ข้อมูลและรูปเก็บในโฟลเดอร์ `ข้อมูลลงเวลา` ข้างตัวโปรแกรม

**ดาวน์โหลด:** [`release/AmaCampTime.zip`](release/AmaCampTime.zip) → แตกไฟล์ → ดับเบิลคลิก `AmaCampTime.exe`
วิธีติดตั้งและใช้งาน: [`README-TH.txt`](README-TH.txt)

## ทำอะไรได้
- **มือถือพนักงาน** (`http://<ip-คอม>:8080/`): เลือกชื่อ + PIN → เซลฟี่ → เข้างาน/ออกงาน, จำชื่อไว้ในเครื่อง, กันกดซ้ำ, PIN ผิด 5 ครั้งล็อก 10 นาที
- **หน้าจอร้าน** (`/kiosk`): QR ให้สแกน, ใครอยู่ในร้าน, รูปเซลฟี่เด้ง 5 วินาที, ปุ่มลงเวลาสำหรับคนไม่มีมือถือ (ถ่ายด้วยเว็บแคม)
- **เจ้าของร้าน** (`/admin`): พนักงาน + ค่าแรง/วัน, ตรวจรูปรายวัน + ธงเตือนลงเวลาแทนกัน (รหัสเครื่อง), สรุปเงินเดือน + ดาวน์โหลด Excel, พิมพ์ QR, เปิดเองตอนเปิดคอม, ไฟล์สำรอง
- สำรองไฟล์ข้อมูลทุกวัน (เก็บ 60 วัน + วันที่ 1 ทุกเดือน), ลบรูปเก่ากว่า 180 วัน, กันคอม Sleep ระหว่างเปิดโปรแกรม

## ไฟล์ข้อมูล (`ข้อมูลลงเวลา/`)
`settings.json` · `employees.json` · `devices.json` · `punches.jsonl` (บันทึกเวลา เขียนต่อท้ายทีละบรรทัด) · `รูป/ปี-เดือน/*.jpg` · `สำรอง/วันที่/`

## สำหรับนักพัฒนา
```bash
go test ./...                                     # ทดสอบ logic
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o AmaCampTime.exe .
AMACAMP_NO_BROWSER=1 AMACAMP_DATA=/tmp/d AMACAMP_PORT=18080 go run .   # รันทดสอบ
node dev/e2e.js http://localhost:18080 http://<lan-ip>:18080/ shots     # ทดสอบในเบราว์เซอร์ (Playwright)
```
ตัวแปร: `AMACAMP_DATA` (โฟลเดอร์ข้อมูล), `AMACAMP_PORT`, `AMACAMP_URL` (กำหนดที่อยู่ใน QR เองถ้าตรวจผิดการ์ด), `AMACAMP_NO_BROWSER`
QR ใช้ [qrcodejs](https://github.com/davidshimjs/qrcodejs) (MIT, ฝังอยู่ใน `web/`)
