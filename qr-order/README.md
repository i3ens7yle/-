# ระบบสั่งอาหารผ่าน QR Code

ลูกค้าสแกน QR ที่โต๊ะ → เลือกเมนู → กดสั่ง → ออร์เดอร์เด้งขึ้นจอพนักงานทันที พร้อมเสียงเตือน

## มีอะไรบ้าง

| หน้า | ใครใช้ | ทำอะไรได้ |
|---|---|---|
| `/?table=5&k=...` (จาก QR) | ลูกค้า | ดูเมนู กดเพิ่มลงตะกร้า ใส่หมายเหตุ สั่ง ดูสถานะ (รอร้านรับ / กำลังทำ / เสิร์ฟแล้ว) ดูยอดโต๊ะ เรียกพนักงาน ขอเช็คบิล |
| `/staff` | พนักงาน (ใส่ PIN) | **ออร์เดอร์**: ใหม่ → กำลังทำ → เสิร์ฟแล้ว · **ดูตามโต๊ะ**: 20 โต๊ะ ยอดแต่ละโต๊ะ กดดูว่าโต๊ะนั้นสั่งอะไรบ้าง ปิดบิล · **เมนูหมด**: ปิดเมนูที่หมด · ยอดขายวันนี้ |
| `/qr` | เจ้าของร้าน | พิมพ์ QR Code ทั้ง 20 โต๊ะ |

## เริ่มใช้งาน (คอมหรือโน้ตบุ๊กในร้าน)

1. ติดตั้ง Node.js จาก https://nodejs.org (เลือกรุ่น LTS)
2. เปิดโฟลเดอร์ `qr-order` แล้วพิมพ์ในหน้าต่างคำสั่ง:
   ```
   npm install
   npm start
   ```
3. เปิด `http://localhost:3000/staff` ใส่ PIN (ตั้งต้นคือ `1234`)
4. กด **พิมพ์ QR โต๊ะ** → ลองสแกน 1 โต๊ะด้วยมือถือที่ต่อ **Wi-Fi ร้าน** → ถ้าเปิดได้ค่อยพิมพ์ทั้งหมด

> คอมเครื่องนี้ต้องเปิดไว้ตลอดเวลาที่ร้านเปิด และลูกค้าต้องต่อ Wi-Fi ร้าน
> ถ้าอยากให้ลูกค้าใช้เน็ตมือถือตัวเองได้ ให้นำขึ้นคลาวด์ (ดูด้านล่าง)

## แก้ไขร้าน / เมนู

- **`config.json`**: ชื่อร้าน (`shopName`), คำโปรย (`tagline`), โลโก้ (`logo`), จำนวนโต๊ะ (`tables`), PIN พนักงาน (`staffPin`)
- **เปลี่ยนโลโก้**: เอารูปใหม่ไปทับไฟล์ `public/logo.jpg` (รูปสี่เหลี่ยมจัตุรัส ประมาณ 480×480 จะโหลดเร็วบนมือถือ)
- **`menu.json`**: หมวด (`categories`) และเมนู (`items`) แก้ชื่อหรือราคาแล้วกดบันทึก ไม่ต้องรีสตาร์ท ลูกค้าเห็นราคาใหม่เมื่อรีเฟรชหน้า
  ```json
  { "id": "fries", "cat": "fried", "name": "เฟรนช์ฟรายส์", "price": 49 }
  ```
  `id` เป็นภาษาอังกฤษไม่ซ้ำกัน `cat` ต้องตรงกับ `id` ของหมวด `desc` ใส่หรือไม่ใส่ก็ได้
- **เปลี่ยน PIN ก่อนเปิดร้านจริง** ไม่อย่างนั้นใครก็เข้าหน้าพนักงานได้

## ข้อควรรู้

- ข้อมูลออร์เดอร์เก็บใน `data/state.json` ส่วนรหัสลับของ QR เก็บใน `data/secret.txt`
  **ห้ามลบ `secret.txt`** ถ้าลบไป QR ที่พิมพ์ไว้จะใช้ไม่ได้ ต้องพิมพ์ใหม่ทั้งหมด
- **เปิดโต๊ะ**: ลูกค้าสั่งได้เฉพาะโต๊ะที่พนักงานกด "เปิดโต๊ะ" แล้ว (ในแท็บ "ดูตามโต๊ะ" หรือกดจากแถบแจ้งเตือนตอนลูกค้ากดเรียกพนักงาน) พอปิดบิล โต๊ะจะปิดเองอัตโนมัติ คนที่ถ่ายรูป QR กลับบ้านจึงสั่งเล่นไม่ได้ ถ้าไม่ต้องการระบบนี้ ให้ตั้ง `"requireOpenTable": false` ใน `config.json`
- **ย้าย / รวมโต๊ะ**: แท็บ "ดูตามโต๊ะ" → แตะโต๊ะ → "ย้าย / รวมโต๊ะ" → เลือกโต๊ะใหม่ เลือกโต๊ะว่าง = ย้าย (รายการที่สั่งไว้ตามไปด้วย) เลือกโต๊ะที่มีลูกค้า = รวมเป็นบิลเดียว มือถือลูกค้าที่โต๊ะเดิมจะขึ้นข้อความให้ไปสแกน QR ที่โต๊ะใหม่
- QR แต่ละโต๊ะมีรหัสลับ (`k=...`) คนนอกร้านจึงเดาลิงก์มาสั่งเล่นไม่ได้
- ราคาคิดจาก `menu.json` ฝั่งร้านเสมอ ลูกค้าแก้ราคาจากมือถือไม่ได้
- กด **ปิดบิล** แล้ว โต๊ะจะว่าง ลูกค้าคนต่อไปที่สแกนจะไม่เห็นรายการของโต๊ะก่อน

## นำขึ้นคลาวด์ (ลูกค้าใช้เน็ตมือถือได้)

ใช้บริการที่รัน Node.js ได้และ **มีดิสก์ถาวร** เช่น Railway, Render (แบบมี Disk) หรือ VPS ทั่วไป
ตั้ง environment variables ดังนี้

| ตัวแปร | ความหมาย |
|---|---|
| `PUBLIC_URL` | ลิงก์เว็บจริง เช่น `https://myshop.example.com` (ใช้สร้าง QR) |
| `STAFF_PIN` | PIN พนักงาน |
| `TABLE_SECRET` | ข้อความลับยาวๆ อะไรก็ได้ ตั้งครั้งเดียวแล้วอย่าเปลี่ยน (QR จะใช้ได้ตลอด) |
| `DATA_DIR` | โฟลเดอร์บนดิสก์ถาวรสำหรับเก็บออร์เดอร์ |
