# ⏱ ระบบลงเวลาพนักงานด้วย QR Code

ระบบตอกบัตรสำหรับร้านเล็ก–กลาง ใช้ **Google Sheet + Apps Script** (ฟรี ไม่ต้องเช่าเซิร์ฟเวอร์)

```
┌──────────── แท็บเล็ตที่ร้าน ────────────┐          ┌──── มือถือพนักงาน ────┐
│  QR เปลี่ยนทุก 30 วินาที                 │  สแกน →  │  เลือกชื่อ + PIN        │
│  [ไม่มีมือถือ? ลงเวลาที่เครื่องนี้]        │          │  ถ่ายเซลฟี่              │
│  อยู่ในร้านตอนนี้ / ลงเวลาล่าสุด          │          │  [เข้างาน] [ออกงาน]     │
└──────────────────────────────────────────┘          └────────────────────────┘
                          ↓ บันทึกลง Google Sheet + รูปเก็บใน Google Drive
```

- **พนักงานมีมือถือ** → สแกน QR บนแท็บเล็ตด้วยกล้องมือถือ (ไม่ต้องลงแอป) ครั้งแรกเลือกชื่อ+ใส่ PIN ครั้งต่อไปมือถือจำไว้ให้
- **พนักงานไม่มีมือถือ** → กดปุ่ม "ไม่มีมือถือ? ลงเวลาที่เครื่องนี้" บนแท็บเล็ต เลือกชื่อ ใส่ PIN ถ่ายรูป
- **เจ้าของร้าน** → เปิด Google Sheet ดูบันทึกได้ทันที + กดสร้าง "สรุปรายเดือน" (ชั่วโมงทำงาน, มาสาย, ลืมลงเวลา) ไว้คิดค่าแรง

## สิ่งที่ต้องมี

- บัญชี Google (Gmail) ของร้าน
- แท็บเล็ตหรือมือถือเก่า 1 เครื่อง ตั้งไว้ที่ร้าน ต่อ Wi-Fi + เสียบสายชาร์จ

## วิธีติดตั้ง (ประมาณ 10 นาที)

1. เปิด <https://sheets.new> สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `ลงเวลาพนักงาน`
2. เมนู **ส่วนขยาย → Apps Script**
3. ในไฟล์ `Code.gs` ลบโค้ดเดิมทิ้งทั้งหมด แล้ววางโค้ดจากไฟล์ [`Code.gs`](Code.gs)
4. กดปุ่ม **＋** ข้าง "ไฟล์" → **HTML** → ตั้งชื่อ `Index` (พิมพ์แค่ Index) แล้ววางโค้ดจาก [`Index.html`](Index.html)
5. กด 💾 บันทึก
6. กลับไปที่ Google Sheet → **รีเฟรชหน้า** → จะมีเมนู **⏱ ระบบลงเวลา** → กด **1) ตั้งค่าเริ่มต้น**
   - Google จะขอสิทธิ์ → เลือกบัญชี → ถ้าขึ้น "Google ไม่ได้ยืนยันแอปนี้" กด **ขั้นสูง → ไปที่ … (ไม่ปลอดภัย)** → **อนุญาต**
     (เป็นสคริปต์ของคุณเอง ขอสิทธิ์ Sheet นี้ + Drive สำหรับเก็บรูปเซลฟี่)
7. แท็บ **ตั้งค่า** → แก้ `SHOP_NAME` (ชื่อร้าน) และ **เปลี่ยน `ADMIN_PIN`** (ค่าเริ่มต้น 9999)
8. แท็บ **พนักงาน** → ลบแถวตัวอย่าง แล้วใส่พนักงานจริง

   | รหัส | ชื่อ | PIN | เวลาเริ่มงาน | สถานะ |
   |---|---|---|---|---|
   | E01 | สมชาย | 4821 | 16:00 | ทำงาน |
   | E02 | มานี | 0193 | 17:00 | ทำงาน |

   - **PIN** ตั้งให้แต่ละคนไม่ซ้ำกัน 4–6 หลัก (คอลัมน์นี้ตั้งเป็นข้อความไว้แล้ว เลข 0 นำหน้าไม่หาย)
   - **เวลาเริ่มงาน** ใช้คำนวณมาสาย (ว่างได้)
   - **สถานะ** ใส่ `ลาออก` หรือ `ระงับ` เมื่อเลิกจ้าง → ชื่อจะหายจากหน้าลงเวลา แต่ประวัติยังอยู่
9. กลับไป Apps Script → ปุ่ม **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ไอคอนเฟือง ⚙ → เลือก **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน** ← สำคัญ ไม่งั้นพนักงานต้องล็อกอิน Google
   - กด **ทำให้ใช้งานได้**
10. กลับไป Sheet → เมนู **⏱ ระบบลงเวลา → 2) ดูลิงก์หน้าจอร้าน** → เปิดลิงก์นั้นบนแท็บเล็ตของร้าน → ใส่ `ADMIN_PIN` → เสร็จ 🎉

> **แก้โค้ดภายหลัง:** หลังวางโค้ดใหม่ ต้องไปที่ Deploy → **จัดการการทำให้ใช้งานได้** → ✏️ แก้ไข → เวอร์ชัน: **เวอร์ชันใหม่** → ทำให้ใช้งานได้ (ลิงก์เดิมใช้ต่อได้ ไม่ต้องตั้งแท็บเล็ตใหม่)

## ตั้งค่าแท็บเล็ตที่ร้าน

- เปิดลิงก์หน้าจอร้านใน Chrome/Safari แล้ว "เพิ่มไปยังหน้าจอหลัก" จะได้เปิดง่าย
- ตั้งให้ **จอไม่ดับ** (ระบบพยายามกันจอดับให้อยู่แล้ว แต่ตั้งในเครื่องด้วยจะชัวร์กว่า)
- Android: เปิด **ปักหมุดหน้าจอ (Screen pinning)** / iPad: เปิด **Guided Access** กันคนออกจากหน้านี้
- วางให้กล้องมือถือสแกนถึงง่าย ระดับอก

## ค่าในแท็บ "ตั้งค่า"

| ชื่อค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `SHOP_NAME` | ร้านของเรา | ชื่อร้านบนหน้าจอ |
| `ADMIN_PIN` | 9999 | รหัสเปิดหน้าจอร้าน **เปลี่ยนทันที** |
| `QR_SECONDS` | 30 | QR เปลี่ยนทุกกี่วินาที |
| `REQUIRE_PHOTO` | TRUE | บังคับถ่ายเซลฟี่ (FALSE = ไม่บังคับ) |
| `MIN_GAP_MINUTES` | 2 | กันกดเข้างาน/ออกงานซ้ำ |
| `MAX_SHIFT_HOURS` | 16 | เข้า–ออกห่างเกินนี้ = ถือว่าลืมลงเวลาออก |

## สรุปรายเดือน (ไว้คิดค่าแรง)

เมนู **⏱ ระบบลงเวลา → สร้างสรุปรายเดือน** → ใส่เดือน เช่น `2026-11` หรือ `2569-11`
จะได้แท็บใหม่ `สรุป 2026-11` มี 2 ตาราง:

1. **รวมรายคน** — วันที่มาทำงาน, ชั่วโมงรวม, มาสายรวม (นาที), จำนวนครั้งที่สาย, ลงเวลาไม่ครบ
2. **รายละเอียดรายวัน** — เข้า/ออก/ชั่วโมง/สาย/หมายเหตุ ("ลืมลงเวลาออก", "ยังทำงานอยู่")

รองรับ **กะดึกข้ามเที่ยงคืน** เช่น เข้า 16:00 ออก 00:30 → นับเป็นวันที่เข้างาน 8.5 ชั่วโมง

ถ้ามีคนลืมลงเวลา เจ้าของร้านเพิ่มแถวในแท็บ **บันทึกเวลา** เองได้ (ใส่คอลัมน์ เวลาบันทึก/รหัส/ชื่อ/ประเภท ให้ครบ) แล้วสร้างสรุปใหม่

## กันโกงได้แค่ไหน

| วิธีโกง | ระบบกันยังไง |
|---|---|
| ถ่ายรูป QR ไว้สแกนจากบ้าน | QR เปลี่ยนทุก 30 วิ ใช้ได้ไม่เกิน ~1 นาที |
| เปิดลิงก์เดิมซ้ำ | หลังสแกนมีเวลา 5 นาที และใช้ลงเวลาได้ครั้งเดียว |
| ปลอมลิงก์/แก้รหัสใน QR | QR มีลายเซ็นดิจิทัล (HMAC) ปลอมไม่ได้ |
| ลงเวลาแทนเพื่อน | ต้องรู้ PIN ของเพื่อน + มีรูปเซลฟี่ทุกครั้ง ตรวจย้อนหลังได้ |
| เดา PIN | ผิด 5 ครั้งล็อก 10 นาที |
| ให้คนในร้านส่งรูป QR ทาง LINE ทันที | ยังทำได้ภายใน ~1 นาที → **รูปเซลฟี่** คือตัวจับ (พื้นหลังไม่ใช่ร้าน) |

ถ้าสงสัยว่ารหัสรั่ว กดเมนู **เปลี่ยนรหัสลับของ QR** ได้ตลอด

## เรื่อง PDPA (กฎหมายข้อมูลส่วนบุคคล)

รูปเซลฟี่และเวลาเข้างานเป็นข้อมูลส่วนบุคคล ควร:
- แจ้งพนักงานเป็นลายลักษณ์อักษรว่าเก็บอะไร เพื่ออะไร (ลงเวลา/คิดค่าแรง) เก็บนานเท่าไร
- เก็บรูปเท่าที่จำเป็น เช่น ลบโฟลเดอร์ `รูปลงเวลาพนักงาน` ใน Drive ที่เก่ากว่า 3–6 เดือน
- ไม่แชร์ Sheet/โฟลเดอร์รูปให้คนที่ไม่เกี่ยวข้อง

(ระบบนี้ **ไม่ได้** ทำสแกนจดจำใบหน้า จึงไม่ได้เก็บข้อมูลชีวภาพ แค่เก็บรูปไว้ตรวจด้วยตา)

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| มือถือพนักงานขึ้น error / หน้าขาว | มักเกิดเมื่อมือถือล็อกอิน Google หลายบัญชี → เปิดลิงก์ในโหมดไม่ระบุตัวตน หรือเบราว์เซอร์อื่น |
| พนักงานต้องล็อกอิน Google | ตอน Deploy ยังไม่ได้เลือก "ผู้มีสิทธิ์เข้าถึง: ทุกคน" |
| แก้โค้ดแล้วไม่เปลี่ยน | ต้อง Deploy เป็น **เวอร์ชันใหม่** (ดูข้อ 10) |
| PIN ที่ขึ้นต้นด้วย 0 ใช้ไม่ได้ | คอลัมน์ PIN ต้องเป็นข้อความ (กด "ตั้งค่าเริ่มต้น" อีกครั้งจะตั้งให้) แล้วพิมพ์ PIN ใหม่ |
| QR ขึ้นจาง "กำลังสร้าง QR ใหม่" | แท็บเล็ตเน็ตหลุด รอสักครู่ระบบจะลองใหม่เอง |
| ลืม ADMIN_PIN | ดูในแท็บ ตั้งค่า ของ Sheet |

## สำหรับนักพัฒนา

```bash
node attendance/dev/test.js      # ทดสอบ logic ทั้งหมดด้วย Apps Script จำลอง
node attendance/dev/preview.js   # เปิดหน้าเว็บจริงใน Chromium + ถ่ายภาพหน้าจอทุกขั้นตอน
```

`dev/harness.js` จำลอง SpreadsheetApp / DriveApp / CacheService ฯลฯ ให้ `Code.gs` รันบน Node ได้
ไฟล์ในโฟลเดอร์ `dev/` ไม่ต้องอัปโหลดขึ้น Apps Script
